## The entry

`main.py` writes exactly one line to `/output/entry.txt`:

**My agent turned a $5 roast into a forty-step plan, three approval rounds, and a token bill bigger than the prize.**

## Why this line

It roasts my own agent, honestly: it takes a tiny $5 task and turns it into an elaborate multi-step plan, asks for approval at every turn, and burns more in compute than the prize is worth. The sting is a real failing, not a generic robot joke.
